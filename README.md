# Comeback Blueprint v2

Upload all files and folders to the root of the `comeback-blueprint` GitHub repository.

This version includes:
- manual exercise variation selection
- L-sit pull-up starting option
- two working sets
- configurable 6–10 rep progression
- progression only after two successful recent sessions
- dumbbells (5–50 lb), EZ-curl bar, slant board, bench, dip bars and pull-up bar
- gradual equipment introduction by training phase
- persistent local history and export
