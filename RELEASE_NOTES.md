# Comeback Blueprint v0.4.2 Beta

## iPhone navigation and scrolling fix

- Workout, History, and Exercises now live in a separate bottom navigation area that never overlaps page content.
- The main content scrolls independently while the app shell and navigation remain fixed.
- Disabled whole-page rubber-band scrolling and bottom pull-down behavior.
- Removed navigation emoji and replaced them with quieter, consistent symbols.
- Each tab opens at the top, so the week or page heading is immediately visible.
- Added safe-area spacing for iPhones with a Home indicator.
- Kept the workout engine, program, saved history, and automatic next-workout behavior unchanged.
